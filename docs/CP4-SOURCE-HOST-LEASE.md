1. Load/validate current snapshot; malformed/unreadable state is identity_mismatch.
2. Exactly one matching ticket, pending with no candidate/result/interruption/
   issues; otherwise not_permitted. Module/step must be explicitly admitted and
   next current registry pack-source step after the ordered valid retained prefix;
   otherwise not_permitted. Retained settling CP4 step/payload cannot open new tools.

   CP0 Run CP4 authorization and required-edge status remain existing scheduler

4. Validate pack hash/Run, unique current heads, bound head/hash/status and complete

   Every scheduler bound producer is authenticated; no interesting-producer subset.

   blobs must match exact chain prefixes and allowed repair policy. Current CP4
   has one step/no within-attempt repair. Real number1 consumer repair is allowed

   actual pack IDs; CP4 empty scope is not_permitted. Recheck current snapshot
