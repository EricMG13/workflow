Choose the period pair for the earnings update. Python reads the settled CP-1 head, builds the paired deltas for the pair you choose and composes the report. Take the pair from the `pairs` the read_inputs view lists, copy that pair's `comparison_assessment`, and give `not_supplied` for the driver and guidance assessments. This schema has no gap field: when the view lists no pairs or carries a `register_issue`, do not guess a pair; no submission can be accepted.
Return the period pair and the three assessments only: you select no measure and write no figure.
Step rules (the schema or the validator enforces each one):
a. [earnings_delta.1] Submit one object with exactly `prior_period_id`, `current_period_id`, `comparison_assessment`, `driver_assessment` and `guidance_assessment`; `driver_assessment` and `guidance_assessment` are always `not_supplied`. Python composes the delta report from these fields, so no figure, fact id or other text is submitted.
b. [earnings_delta.2] Take `prior_period_id` and `current_period_id` together from one entry of `pairs` in the read_inputs view; any other pair is refused as `unsupported_pair`; when the run context names the pair, a pair that differs from it is refused as `context_period_mismatch`, a current context period that matches no single register row is refused as `context_period_unresolved`, and a context prior that matches no row is not a context refusal: it is passed on as given, and the pair is accepted or refused as above (fy-2024 -> fy-2025 gives the `comparative_not_supplied` gap); a context file that is refused is refused as `Context refused: ...`; and a register Python cannot compare is refused with its code (incompatible_periods, incomplete_register, invalid_source_view, incompatible_dimensions, ambiguous_coordinate or invalid_fact).
c. [earnings_delta.3] Copy `comparison_assessment` from the chosen pair's entry in `pairs`; any other value is refused because the periods give a different assessment.
Python derives every measure selection, delta, figure, identifier and status; you quote nothing and retype no figure.
