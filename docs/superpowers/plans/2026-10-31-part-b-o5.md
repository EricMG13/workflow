## Task 4: Adapters, recordings and the live gate [security + money: mx-adversary]

**Files:** `model/adapter.py`; tests `test_adapter.py`, `test_gate.py`.

- `ModelAdapter` is a `Protocol`: `config_id: str`, `ruling: Path | None` (:428-430) plus `complete(request: TurnRequest, *, invocation_digest: str, call_index: int, reservation_id: str) -> AdapterReply` (an addition; the call shape fixes only the attributes). `AdapterReply(kind: Literal["ok","not_sent","sent_known","sent_unknown"], turn: Turn | None, raw: bytes | None, http_status: int | None, error_class: str | None, first_byte_at, started_at, finished_at)`. **`complete` sends at most one request and never retries or resends (F1).**
- `RecordedAdapter` (`ruling is None`, `recorded_adapter(model, recordings)`): reads every `*.jsonl` under `recordings`, one object per line `{"invocation_digest","call_index","response"}` (:451-453), keyed `(digest, call_index)`. Duplicate key with a different response -> `RecordingConflict`; bad line -> `RecordingError` with line number; a response without `http_status` -> `RecordingError`. A missing key -> `RecordingMissing(digest, call_index)`, never a default. Reads no environment and no key.
