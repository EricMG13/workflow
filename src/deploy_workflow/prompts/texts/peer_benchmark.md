Peer benchmark: you judge how comparable each listed peer is to the issuer, and name what the pack cannot show. Python reads the peer table, computes every metric, median, difference, position and outlier flag, and applies your comparability judgments to decide which peers enter those statistics. Python copies the issuer's own figures from the settled CP-1 facts. Give each peer an assessment (`peer`, `comparability`, `category`, `rationale`, `evidence`, `limitation`), one `overall` assessment of the peer set, and `gaps` for what the evidence cannot show. Where the evidence for a point is absent, say so in that assessment's `limitation` or in a `gaps` entry rather than filling it in.
Step rules (the schema or the validator enforces each one):
a. [peer_benchmark.1] Python computes every median, position and outlier. A peer you assess Comparable or Partly comparable is included in them, and a Not comparable peer is shown but kept out of every statistic, so choose each `comparability` with that effect in mind; `rules` of the module context gives the minimum number of included peers.
b. [peer_benchmark.2] Write exactly one assessment for each peer listed in `peers.rows` of the module context, its `peer` the row's `label` written exactly, and none for another name or twice. When the peers source is absent, write no assessment.
c. [peer_benchmark.3] Every assessment lists `evidence`, and a Partly comparable assessment states its `limitation`. `overall.confidence` is never High, because the peer figures are desk-supplied and unaudited.
d. [peer_benchmark.4] Each `rationale` is nonblank run text with no bare figure (digits only inside a period or filing label); a figure appears only as `{ref|unit}` with a `ref` and `unit` listed in `cp1_facts`, closed and non-empty; a reference that resolves to no fact, or to a fact whose value is a gap, is refused. State no instrument recommendation or recovery conclusion in any text field (`rationale`, `limitation` and gap fields), and leave none blank: a blank `limitation` (of an assessment, when given, or of `overall`) or gap field (`gap`, `why_it_matters`, `affected_analysis`, `action`) is refused.
e. [peer_benchmark.5] Cite each quote verbatim under the locator of its page, and read that page with `read_pages` first; call only the offered tools.
Return judgments and verbatim quotes only: Python fills every identifier, metric, statistic, position, flag and status.
