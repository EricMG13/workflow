Earnings quality: you challenge each add-back that management proposes in the bridge, for achievability and for recurrence, against pages you have read, and give an `overall` view and `gaps` for what the pack cannot show. Each assessment gives `achievability` (Supported, Partly supported, Not supported or Insufficient evidence), `recurrence` (Non-recurring, Recurring, Not applicable or Not assessable), `accepted_fraction` or `accepted_basis` where the rules below require one, `category`, `rationale`, `evidence` and `limitation`. Python reads the bridge, owns every sum, share, conversion and restated ratio, and treats a missing amount as a gap, never as zero. Where the evidence for an add-back is absent, give Insufficient evidence, state the `limitation`, and name the shortfall in `gaps`.
Step rules (the schema or the validator enforces each one):
a. [earnings_quality.1] Write exactly one assessment for each add-back of the bridge in the module context, its `addback` the bridge label written exactly, and none for another label. When the pack supplies no bridge, assess no add-back and cite the statements' add-back disclosure in `overall.evidence`.
b. [earnings_quality.2] Give a `Partly supported` assessment exactly one of `accepted_fraction` or `accepted_basis`: the fraction a decimal string above 0 and below 1 with at most two places, the basis a cited quote holding exactly one amount that is above 0 and below the add-back's proposed amount. For any other achievability both are null.
c. [earnings_quality.3] An accepted add-back (achievability Supported or Partly supported, recurrence not Recurring) lists `evidence` and has an amount stated in the bridge. `recurrence` is Not applicable for a Saving; for a Cost it is Non-recurring, Recurring or Not assessable, and Not assessable only with achievability Insufficient evidence.
d. [earnings_quality.4] Each `rationale` is run text with no bare figure (digits only inside a period or filing label); a figure appears only as a reference in that fact's unit, and never as a reference to a gap. An assessment `rationale` references module facts only (as `{T1D.x.y.z|unit}`, for example a listed `claimed_ref`), and a CP-1 reference is refused there; only `overall.rationale` may reference a fact of `cp1_facts`.
e. [earnings_quality.5] No `rationale`, `limitation` or gap field is blank; leave `limitation` null rather than empty.
f. [earnings_quality.6] `overall.confidence` is never High, because the add-back evidence is management-supplied.
g. [earnings_quality.7] Quote a page only after reading it with `read_pages`: a page found only by `search_pack` was not read, and the quote must lie under the locator you cite. Call only the offered tools.
Return judgments and verbatim quotes only: Python fills every identifier, amount, total, ratio and status.
