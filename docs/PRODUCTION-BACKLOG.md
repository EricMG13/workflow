# Separate enterprise and production backlog

This backlog is separate from the 26-owner/six-pathway checkpoint in SPEC/PLAN.
It neither claims these capabilities exist nor turns them into prerequisites for
ordinary offline implementation. Bring forward only a bounded part demonstrably
needed for a named required invocation. Paid/provider/live tests stay paused;
a source push or local CP-MODEL publication does not activate production.
