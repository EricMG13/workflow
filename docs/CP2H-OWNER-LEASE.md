## Decimal composer: rules, zero / missing / not_applicable kept distinct

Ratings, scale, outlooks and thresholds come from `parse_ratings`; CP-2G ratios from the head. A trigger row maps its source metric label to a CP-2G ratio: "Total debt to EBITDA" -> `total_leverage` (x), "Net debt to EBITDA" -> `net_leverage` (x), "EBITDA to cash interest" -> `interest_coverage` (x), "Free cash flow to total debt" -> `fcf_to_debt` (percent). Threshold "N.NNx" is a multiple; "N.N%" is stored as a fraction (10.0% -> 0.1); "Not stated" is missing.

| Quantity | Recipe |
|---|---|
| Headroom | `threshold - metric` for "Above", `metric - threshold` for "Below"; one subtraction in the 38-digit half-even context equal to the correctly rounded rational. A percent metric gives percentage points: `(a - b).scaleb(2, context)`, unit `pp`, `shown` the exact text plus " pp" (no pp display class: a pending product task, so `report_view.fact_spelling` spells exact text) |
| Reached | strict: `metric > threshold` ("Above"), `metric < threshold` ("Below"); equal is not reached with a known zero headroom (`fixture_boundary`) |
| FY2025 row (T2R.4) | `actual` is an own calculated copy of CP-2G `T2H.6.a25.<field>` (lineage `cp2g:`); `check` is "Reconciled to CP-1" iff it equals the CP-1 reported ratio exactly, else "Differs from CP-1" (the builder asserts equal), "Not compared" when either is missing |
| Forward headroom (T2R.5) | per trigger and case the headroom in FY2026-FY2028; `tightest` the lowest of the three and `tightest_year` its year; missing with the first missing year's reason if any year is missing |
| First year (T2R.6) | the first of the three years the trigger is reached; a year not calculable before it makes the answer unknowable and the fact `missing` with the root reason (threshold first, then the CP-2G limitation); none reached and all calculable is "Not reached by FY2028" |
| Notches (T2R.8) | `abs(position_a - position_b)`, unit `notches`; "lower rated" the agency with the larger position, "Same rating" if equal; outlook "Same" or "Different" |
| Summary (T2R.9, one totals row) | counts of triggers: tested; downgrade reached base/downside; upgrade reached base/downside; not calculable base and not calculable downside (`not_calculable_base`, `not_calculable_down`: triggers whose first-year result for that case is missing). A missing result is counted only in its case's "not calculable", never in a reached count; each T2R.6 claim cites its own case's count (`fixture_total_loss`: base 0, downside 3; positive 0 / 0; gap 1 / 1) |

**Missing and not_applicable.** An unstated threshold makes the trigger's `threshold`, FY2025 `headroom` and `status`, all yearly headrooms, `tightest`, `tightest_year` and both first-year facts `missing` (reason "Not calculable: the trigger threshold is not stated in the agency source"). A missing CP-2G ratio makes the dependent headrooms missing with CP-2G's own limitation while a CP-2G known zero stays a known zero (`fixture_total_loss`: downside coverage 0.00x is a known value, leverage is missing). A withdrawn or "Not rated" agency has `position` `not_applicable` and the pair's `notches`, `lower_rated` and `outlook_match` `not_applicable` with the reason (gap case). **Gap twins carry their settled twin's unit**: `MULTIPLE`, `PERCENT`, `pp`, `notches`, `scale position`, `triggers`. Copies and value classes: source facts (rating cells, thresholds, positions) are `source` with the cited line; calculated facts list `derives_from` (`cp1:<metric>`, `cp2g:<id>` or an own id) and carry `calc:<fact_id>`; analyst cells (`view`, `confidence`, gap text) are `analyst_judgment` with no calculation id; citations are the ordered, de-duplicated concatenation of the own facts' citations in `derives_from` order (upstream citations are appended at run time).
